SAPNDA

Unifying Admin Settings across products in Business Data Cloud

Business Data Cloud brings SAP Analytics Cloud (SAC), Datasphere (DSP), and BDC together under one platform, but each product's admin settings had been built separately and didn't match. With one other UX designer, I worked on making them consistent across all three products.

This project is under NDA, so this page is a high-level summary. Contact me for the full case study.

Platform Figma
Tasks Cross-platform Alignment
Timeline 6 months
Role UX Designer

context

Multiple products under one roof. The admin experience needed to follow.

Each product's admin area had been built independently over time by different teams. Admins moving between products ran into different layouts, interaction patterns, and settings structures, and some settings didn't meet SAP's UX consistency standards.

my work

Two connected workstreams, one consistent admin experience.

Unifying admin settings. I designed a shared layout that became the standard for every admin tab across all three products, and turned it into a page template in the DNA Web UI Kit so future tabs start consistent.

Browser integration and appearance. I brought these settings in line with SAP's consistency standards, including moving the system information bar to design tokens, which is covered in the DNA Web UI Kit case study.

Along the way I ran the audit, iterated on designs through reviews, and wrote specs that development teams across multiple countries could build from, working closely with development, user assistance, and product management.

outcome

Both specs handed off to development, unifying 20 tabs across 3 products.

The settings now meet SAP's consistency standards, and the layout lives in the DNA Web UI Kit for future tabs.
